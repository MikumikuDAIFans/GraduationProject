| 3.5 全天事件冲突 | 创建全天事件，再创建同天事件 | 提示冲突 | ☐ |

## 已知限制与注意事项

1. **ChromaDB 首次启动较慢**：首次创建集合时需要初始化，后续操作会更快
2. **习惯学习需要数据积累**：至少需要 3-5 个同类事件才能形成可靠习惯模式
3. **语义搜索依赖网络**：Gemini Embedding API 需要网络连接，断网时会降级
4. **Celery 定时任务**：提醒和习惯分析依赖 Celery Beat 定时调度，可能需要等待触发周期
5. **单元测试覆盖**：187 个单元测试全部通过，但集成测试仍需手动验证
