## 模板格式要求摘要

| 项目 | 模板要求 |
|------|---------|
| 章标题 (Heading1) | 小3号黑体(15pt)，加粗，左对齐，段前段后0.5行 |
| 节标题 (Heading2) | 4号黑体(14pt)，加粗，左对齐 |
| 条标题 (Heading3) | 小4号黑体(12pt)，不加粗，左对齐 |
| 正文 | 小4号宋体(12pt)，1.5倍行距，两端对齐，首行缩进2字符 |
| 摘要标题 | 小3号黑体(15pt)，居中 |
| 英文标题 | 小3号Times New Roman(15pt) |
| 英文Abstract | Times New Roman，加粗 |
| 英文摘要正文 | 小4号Times New Roman，1.5倍行距 |
| 参考文献标题 | 小3号黑体(15pt)，居中 |
| 参考文献正文 | 小4号宋体+Times New Roman，行距18磅，悬挂缩进 |
| 致谢标题 | 小3号黑体(15pt)，居中 |
| 图表编号 | 阿拉伯数字分章编号（图3.1、表3.1） |
| 目次顺序 | 摘要 → Abstract → 各章 → 结论 → 参考文献 → 致谢 → 附录 |

## 总结

对照2026版毕业设计说明书格式模板，共发现并修正了149处格式问题。主要问题集中在：

1. **标题字体错误**（115处）：所有层级标题的字体从宋体/Times New Roman改为黑体
2. **特殊章节格式缺失**（6处）：摘要、英文标题、Abstract、参考文献、致谢的字体和对齐方式
3. **参考文献样式错误**（25处）：从正文样式改为ThesisRef悬挂缩进样式
4. **目次顺序错误**（1处）：参考文献和致谢的顺序

修正后的文档格式已符合2026版模板要求，可进入最终排版和打印阶段。
