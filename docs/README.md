## 📝 文档维护规范

1. **新增文档**：根据文档性质放入对应的分类目录
2. **命名规范**：使用英文大写字母和下划线，如 `FEATURE_NAME.md`
3. **版本管理**：对于迭代文档（如实施计划），保留所有历史版本
4. **敏感信息**：API密钥等敏感信息不得直接提交到代码库，仅保留参考清单
